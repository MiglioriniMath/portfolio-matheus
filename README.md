## Puppertino como referência
O projeto não importa o framework inteiro. Foram usados apenas princípios coerentes com
a proposta do site:
- superfícies brancas;
- bordas finas;
- sombras curtas;
- blur seletivo;
- estados hover/active discretos;
- foco azul para teclado;
- componentes modulares para não prejudicar performance.
