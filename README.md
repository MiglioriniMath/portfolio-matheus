# Portfolio Matheus Migliorini — V8

V8 adiciona Hamtaro e Totoro em pixel art à Home.

## Interação
- Os dois passeiam sozinhos pelo grande espaço livre na parte inferior da Home.
- Hamtaro é mais curioso e rápido.
- Totoro passeia um pouco mais devagar.
- Quando o cursor chega perto, eles correm atrás dele.
- A direção do sprite muda entre frente, trás, esquerda e direita.
- O sistema usa as 4 colunas do sprite: parado, passo 1, passo 2 e corrida.
- A interação fica escondida no mobile por enquanto; faremos a versão mobile na etapa de responsividade.
- `prefers-reduced-motion` é respeitado.

## Novos arquivos
- `pets.js`
- `assets/hamtaro-sprites.png`
